  - Guarantees: RFC-7807 error formatting, sub-25ms response time, strict payload sanitization.

Layer 2: Embedding & NLP Transformation Service
  - Components: src/core/embeddings.py, src/core/normalization.py, src/core/similarity.py, engine.py
  - Model: sentence-transformers/all-MiniLM-L6-v2 (384-dimensional dense embeddings)
  - Math: L2 Unit Normalization (||v||=1), Bounded Cosine Inner Product [0.0, 1.0], Jaccard Token Overlap.

Layer 3: FAISS Dense Vector Index & Accelerated Retrieval
  - Components: src/indexing/faiss_engine.py, src/indexing/vector_store.py, src/indexing/cache.py
  - Index Type: faiss.IndexFlatIP on normalized vectors (Exact Cosine Equivalence)
  - Memory: 8-bit scalar quantization (ScalarQuantizer) & LRU vector cache (VectorCache).

Layer 4: Relational Persistence & ACID Storage
  - Components: src/storage/database.py, src/storage/models.py, src/storage/repositories.py, database.py
  - Engine: SQLite 3 with Write-Ahead Logging (PRAGMA journal_mode=WAL) & Foreign Key cascading.
  - Idempotency: Complete vector index reconstruction supported via /api/rebuild without data loss.
